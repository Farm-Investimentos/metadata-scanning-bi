    Como ler as conexões

    Mesmo modelo : relatórios apontando para o mesmo dataset
    Duplicado : mesmo nome-base + modelo parecido (ex.: cópias entre workspaces)
    Alta sobreposição : similaridade ≥ 0,5
    Relacionado : compartilham tabelas, medidas ou colunas

    Similaridade = 50% tabelas + 25% medidas + 25% colunas (Jaccard ponderado por IDF, tabelas genéricas como calendário e “_medidas” não contam).

    Cada cartão é um tema-alvo para a nova arquitetura de BIs: as tabelas-fato e dimensões mais usadas pelos relatórios do tema são as candidatas a tabelas-chave do modelo semântico único. Clique para ver o mapa do tema.

    Como a nota é calculada

    100
    Todo relatório começa com 100 pontos
    e perde pontos a cada problema encontrado.
    Exemplo: ninguém abriu (−40) e os dados estão parados há 200 dias (−30) → sobram 30 pontos → Arquivar
    O que a nota recomenda
    04065100
    Arquivarnota abaixo de 40 (ou teste quase sem uso): mover para o BI Histórico
    Revisarnota entre 40 e 65: conversar com o dono
    Manternota acima de 65: está saudável
    Consolidarexiste outro relatório quase igual: juntar no modelo do tema (vale para qualquer nota acima de 40)

    O uso vem do Usage Metrics de cada workspace. Onde ele não existe ou está parado, a nota pode estar mais baixa do que deveria.
